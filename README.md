# Sprint 7 — API testing

Проект автоматизированного тестирования API учебного сервиса Яндекс Самокат.

## Что покрыто тестами

### Создание курьера
- успешное создание курьера;
- невозможность создать двух одинаковых курьеров;
- проверка обязательных полей;
- проверка кода и тела ответа.

### Логин курьера
- успешная авторизация;
- авторизация с неверным паролем;
- авторизация несуществующего курьера;
- авторизация без обязательного поля.

### Создание заказа
Проверены варианты:
- цвет `BLACK`;
- цвет `GREY`;
- оба цвета;
- заказ без указания цвета.

Для вариантов цвета используется параметризация.

### Получение списка заказов
- проверка успешного ответа;
- проверка наличия списка заказов в теле ответа.

## Дополнительные тесты

Также реализованы проверки:
- удаления курьера;
- получения заказа по `track`;
- принятия заказа курьером.

## Особенности реализации

- тесты независимы друг от друга;
- тестовые курьеры удаляются после выполнения тестов;
- тестовые заказы очищаются после проверок;
- данные для курьеров генерируются динамически;
- для вариантов цвета заказа используется `pytest.mark.parametrize`;
- в Allure добавлены понятные шаги выполнения тестов.
